INTEGRATION EXAMPLE
================================================================================

Python integration example:

    import json

    # Load commentary
    with open('kjvstudy_org/data/pauline_commentary.json') as f:
        commentary = json.load(f)

    # Get specific verse commentary
    verse_ref = 'Romans 8:28'
    entry = commentary.get(verse_ref)

    if entry:
        print(entry['analysis'])
        print(entry['historical_context'])
        print(entry['application'])
        for question in entry['questions']:
            print(f"• {question}")

Web API endpoint example:

    @app.get("/api/commentary/{book}/{chapter}/{verse}")
    def get_commentary(book: str, chapter: int, verse: int):
        verse_ref = f"{book} {chapter}:{verse}"
        return commentary.get(verse_ref, {})
